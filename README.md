# NOI 准考证自动下载

登录 NOI 在线报名系统，遍历活动列表，批量下载准考证 PDF。

提供两种使用方式：

- **网页版（推荐）**：在浏览器里管理多个账号，支持手动添加、CSV / Excel 表格导入、自定义下载目录、实时进度与结果展示。
- **命令行版**：适合单账号或脚本调用。

---

## 功能特性

- 一键批量：多个账号依次登录并下载，单个账号失败不影响后续账号
- 账号导入：手动添加，或上传 `.csv` / `.xlsx` 表格批量导入（自动去重、表头识别）
- 目录自定义：网页端可手动输入路径，或调用系统文件夹选择框
- 目录结构可选：按活动区分（默认）、按用户区分、不区分
- 文件名可定制：支持占位符模板；默认 `{original}` 保持服务端原始文件名
- 完成情况：任务结束后显示账号统计、下载份数、未下载活动数与用时
- 结果清晰：每个账号显示成功 / 部分成功 / 失败 / 无可下载，并列出文件与跳过原因
- 自动跳过：未开放准考证的活动会被跳过并说明原因
- 隐私保护：界面、接口返回、日志和下载目录名中的手机号统一脱敏（如 `138****0000`）
- 可选能力：遍历历史活动、显示浏览器窗口以手动完成验证码、设置账号间隔避免风控
- 本地运行：账号密码仅保存在本机内存，服务默认只监听 `127.0.0.1`

## 环境要求

- Windows 10 / 11（macOS、Linux 也可运行；系统文件夹选择框仅支持 Windows）
- Python 3.8 及以上
- 可访问 NOI 报名系统的网络

安装依赖：

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

首次使用需要下载 Chromium 内核（约 150MB），之后无需重复安装。

## 网页版（推荐）

### 启动

**Windows**：双击 `启动网页版.bat`。

**macOS / Linux**（Windows 的 Git Bash 同样适用）：

```bash
chmod +x 启动网页版.sh   # 首次使用，赋予执行权限
./启动网页版.sh
```

启动脚本会自动检查 Python 版本、Python 依赖和 Chromium 内核；缺少依赖时会提示并可直接选择安装。

**任意平台**也可以直接运行：

```bash
python web_app.py
```

启动后会自动打开 <http://127.0.0.1:8765/>。若默认端口被占用会自动顺延，控制台会打印实际地址。

停止服务：在控制台按 `Ctrl+C`。

启动脚本支持透传参数，例如：

```bash
./启动网页版.sh --port 9000 --no-browser
```

可选参数：

| 参数 | 说明 |
| --- | --- |
| `--port 8765` | 指定端口（被占用时自动顺延） |
| `--host 127.0.0.1` | 监听地址，默认仅本机访问 |
| `--no-browser` | 启动时不自动打开浏览器 |
| `--debug` | Flask 调试模式 |

> 安全提示：不要使用 `--host 0.0.0.0` 把服务暴露到局域网或公网，否则同一网络下的其他人可能操作你的账号。

### 使用步骤

**1. 配置下载设置**

- 站点地址：测试站 `https://cspsjtest.noi.cn`，正式站 `https://cspsj.noi.cn`
- 下载目录：可直接输入，或点「浏览…」选择；点「打开」在资源管理器中查看
- 目录结构：
  - 按活动区分（默认）：`下载目录/活动名称/准考证.pdf`
  - 按用户区分：`下载目录/用户/准考证.pdf`
  - 不区分：所有准考证直接放在下载目录中
- 文件名格式：默认 `{original}`，保持服务端原始文件名；可组合占位符自定义（见下文）
- 登录等待：单个账号等待登录完成的最长时间，默认 60 秒
- 账号间隔：相邻账号之间的等待，默认 1 秒，用于降低触发风控的概率
- 显示浏览器窗口：遇到图形 / 滑块验证码时勾选，任务会打开可见浏览器，可在等待时间内手动完成验证码
- 包含历史活动：额外遍历「历史活动」，往期活动通常已关闭准考证下载

**2. 添加账号**

手动添加：填写账号、密码、备注（可选），点「添加」。

表格导入：点击或拖拽上传表格，支持 `.csv`、`.txt`、`.xlsx`、`.xlsm`。

表格示例（号码仅为脱敏示例，请填写真实账号）：

| 账号 | 密码 | 备注 |
| --- | --- | --- |
| 138****0000 | 你的密码 | 张三 |
| 139****0001 | 另一个密码 | 李四 |

- 首行表头会自动识别（账号 / 用户名 / 手机号、密码、备注 / 姓名）
- 没有表头时，默认第 1 列为账号、第 2 列为密码、第 3 列为备注
- 表格可用 UTF-8 或 GBK 编码；旧版 `.xls` 请先另存为 `.xlsx`
- 重复账号会自动跳过，并在上传区域下方提示原因
- 可点击「下载模板」获取带说明的 CSV 模板（以 `#` 开头的行会被忽略）

**3. 开始下载**

点击「开始下载（N 个账号）」，页面会实时显示：

- 进度条与当前处理的账号
- 每个账号的状态、下载文件、跳过原因
- 运行日志（可展开）

**4. 查看结果**

- 任务结束后，结果区顶部会显示完成情况：账号总数、成功 / 失败统计、下载份数、未下载活动数与用时
- 点击结果卡片右上角的「打开下载目录」直接打开保存位置
- 单个活动的跳过原因（如「未开放下载准考证」）可在结果项中展开查看

### 下载目录结构

网页版支持三种目录结构，在「下载设置」中选择，默认按活动区分。

**按活动区分（默认）**

```
<下载目录>/
├── NOIP 2026/
│   └── LN-0000张三.pdf
└── CSP-S 2026 第一轮认证/
    └── LN-0001李四.pdf
```

**按用户区分**

```
<下载目录>/
├── 张三_138xxxx0000/
│   └── LN-0000张三.pdf
└── 李四_139xxxx0001/
    └── LN-0001李四.pdf
```

**不区分**

```
<下载目录>/
├── LN-0000张三.pdf
└── LN-0001李四.pdf
```

用户目录名使用备注 + 脱敏账号，不会包含完整手机号。文件重名时会自动追加 `(2)`、`(3)`。

### 文件名格式

默认值为 `{original}`，即保持服务端返回的原始文件名不变。可以组合以下占位符自定义：

| 占位符 | 含义 |
| --- | --- |
| `{original}` | 服务端原始文件名（不含 `.pdf`） |
| `{activity}` | 活动名称 |
| `{user}` | 备注 + 脱敏账号（与用户目录名一致） |
| `{account}` | 脱敏账号 |
| `{note}` | 备注 |
| `{id}` | 活动 ID |
| `{date}` | 下载日期（YYYYMMDD） |

扩展名 `.pdf` 会自动补全。例如：

- 按用户区分 + `{activity}_{original}` → `张三_138xxxx0000/NOIP 2026_LN-0000张三.pdf`
- 不区分 + `{user}_{activity}_{original}` → `LN-0000张三.pdf` 前带上用户与活动，便于区分

> 命令行版仍使用「活动名_原始文件名.pdf」，不受网页版设置影响。

## 命令行版

适合单账号下载或接入其他脚本。

```bash
# 交互式输入账号密码（密码不回显）
python download_tickets.py

# 直接传参
python download_tickets.py -u 你的账号 -p "你的密码"

# 同时遍历历史活动，并指定目录
python download_tickets.py -u 账号 -p 密码 --history -o "D:\准考证"

# 显示浏览器窗口（处理验证码）
python download_tickets.py -u 账号 -p 密码 --headed
```

参数说明：

| 参数 | 说明 |
| --- | --- |
| `-u, --user` | 用户名 / 手机号 / 邮箱 |
| `-p, --password` | 密码（不填则交互式输入） |
| `--base-url` | 站点地址，默认 `https://cspsjtest.noi.cn` |
| `-o, --out` | 保存目录，默认 `./tickets` |
| `--history` | 同时遍历「历史活动」 |
| `--only-enrolled` | 仅处理已报名的活动 |
| `--page-size` | 每页活动数，默认 50 |
| `--headed` | 显示浏览器窗口 |
| `--login-timeout` | 登录等待秒数，默认 60 |

退出码：`0` 正常；`1` 执行异常；`2` 登录失败；`3` 接口解析失败。

## 工作原理

1. 使用 Playwright 打开登录页，填写账号密码登录，获取会话 Cookie；
2. 调用活动列表接口 `/api/contestant/activity/list` 获取活动与活动 ID
   （该接口使用自定义二进制协议：类哈希 + varint + 长度前缀字符串，脚本已内置编解码）；
3. 对每个活动请求 `/api/contestant/activity/download_ticket?id=<活动ID>`，把返回的 PDF 保存到本地。

接口返回的错误消息（如「未开放下载准考证」「会话已过期」）会被解析并展示为跳过或失败原因。

## 安全与隐私

- 网页服务默认只监听 `127.0.0.1`，仅本机可访问；
- 账号密码只保存在运行中进程的内存里，网页不回显密码，关闭服务即清除；
- 手机号在界面、接口返回、运行日志和下载目录名中均脱敏（如 `138****0000`），不会出现完整号码；
- 浏览器本地存储（localStorage）只保存站点地址、下载目录等设置，不保存密码；
- 下载的准考证包含姓名等个人信息，请妥善保管，不要随意分享；
- 请只操作本人账号或已获得授权的账号，并遵守网站使用条款。

## 常见问题

**1. 登录失败，或报 `net::ERR_CONNECTION_CLOSED`**

连续大量登录可能触发站点风控。处理方式：

- 等待几分钟后重试；
- 增大「账号间隔」；
- 勾选「显示浏览器窗口」，在登录等待时间内手动完成验证码；
- 先用普通浏览器确认账号能正常登录、密码未过期。

**2. 提示「未开放下载准考证」**

活动尚未开放准考证下载，或下载通道已关闭，与脚本无关。可在活动详情页查看准考证开放时间。

**3. 表格导入失败**

- 确认扩展名为 `.csv` / `.xlsx`；
- 首行建议使用表头：`账号,密码,备注`；
- 旧版 `.xls` 请另存为 `.xlsx`；
- 检查是否有空账号、空密码行（会提示具体行号）。

**4. 端口被占用**

默认使用 8765，被占用时会自动顺延。以控制台打印的地址为准，或使用 `--port` 指定其他端口。

**5. 下载目录无法写入或打开**

确认路径存在且有写权限；网页端可用「浏览…」重新选择。路径支持相对路径（相对于项目目录）和绝对路径。

**6. 网页打不开**

确认启动窗口未被关闭，且安全软件没有拦截本地端口；访问控制台打印的地址。

**7. 切换到正式站**

在网页「站点地址」中改为 `https://cspsj.noi.cn`，或命令行使用 `--base-url https://cspsj.noi.cn`。建议先用测试账号验证。

**8. 为什么多账号是串行执行？**

串行登录更稳定，也能降低触发风控的概率。大规模使用时建议适当增大账号间隔，分批执行。
