# NOI 准考证、证书下载与成绩查询

登录 NOI 在线报名系统，批量完成三件事：**下载准考证**、**下载证书**、**查询历史成绩**。

网页版三项功能并列，支持多账号、表格导入、进度与结果展示；命令行版仅提供准考证下载。

---

## 三大功能

| 功能 | 做什么 | 输出 |
| --- | --- | --- |
| **准考证下载** | 遍历账号的当前活动（可选历史活动），下载准考证 | PDF 文件 |
| **证书下载** | 遍历账号的当前与历史活动，下载获奖 / 等级证书 | PDF 文件 |
| **历史成绩查询** | 查询账号历史活动的成绩，按活动展示各题得分与总分 | 网页表格 + Excel 导出 |

三项任务均使用同一套账号列表与登录设置，但同一时间只能执行其中一项，避免并发登录触发风控。

---

## 功能特性

### 通用能力

- 多账号批量：依次登录处理，单个账号失败不影响后续账号
- 账号导入：手动添加，或上传 `.csv` / `.xlsx` 表格（自动去重、表头识别）
- 本地运行：账号密码仅保存在本机内存，服务默认只监听 `127.0.0.1`
- 隐私保护：界面、接口返回、日志和目录名中的手机号统一脱敏（如 `138****0000`）

### 准考证下载

- 批量下载当前活动准考证，可勾选同时遍历历史活动
- 支持按活动 / 按用户 / 不区分三种目录结构
- 支持文件名占位符模板，默认保持服务端原始文件名
- 自动跳过未开放准考证的活动并说明原因

### 证书下载

- 支持获奖证书与等级证书，可分别勾选
- 遍历当前与历史活动，自动尝试下载可用的证书
- 统一保存到 `<下载目录>/证书/`，沿用目录结构设置
- 未开放或无证书时跳过，并给出原因

### 历史成绩查询

- 按活动分组展示姓名、准考证号、各题得分、总成绩与备注
- 各题得分同时提供按题目分列与「各题得分」明细
- 缺考、暂无成绩、查询失败均有明确标注
- 支持导出 Excel，包含汇总表、题目得分明细与分活动工作表

## 环境要求

- Windows 10 / 11（macOS、Linux 也可运行；系统文件夹选择框仅支持 Windows）
- Python 3.8 及以上
- 可访问 NOI 报名系统的网络

安装依赖：

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

首次使用需要下载 Chromium 内核（约 150MB），之后无需重复安装。

## 网页版（推荐）

### 启动

**Windows**：双击 `启动网页版.bat`。

**macOS / Linux**（Windows 的 Git Bash 同样适用）：

```bash
chmod +x 启动网页版.sh   # 首次使用，赋予执行权限
./启动网页版.sh
```

启动脚本会自动检查 Python 版本、Python 依赖和 Chromium 内核；缺少依赖时会提示并可直接选择安装。

**任意平台**也可以直接运行：

```bash
python web_app.py
```

启动后会自动打开 <http://127.0.0.1:8765/>。若默认端口被占用会自动顺延，控制台会打印实际地址。

停止服务：在控制台按 `Ctrl+C`。

启动脚本支持透传参数，例如：

```bash
./启动网页版.sh --port 9000 --no-browser
```

可选参数：

| 参数 | 说明 |
| --- | --- |
| `--port 8765` | 指定端口（被占用时自动顺延） |
| `--host 127.0.0.1` | 监听地址，默认仅本机访问 |
| `--no-browser` | 启动时不自动打开浏览器 |
| `--debug` | Flask 调试模式 |

> 安全提示：不要使用 `--host 0.0.0.0` 把服务暴露到局域网或公网，否则同一网络下的其他人可能操作你的账号。

### 快速开始

1. 在「下载设置」中确认站点地址与下载目录。
2. 在「账号列表」中手动添加账号，或上传 CSV / Excel 表格。
3. 按需选择一项功能：

   - 点击「开始下载」→ 下载准考证
   - 点击「下载证书」→ 下载获奖 / 等级证书
   - 点击「查询历史成绩」→ 查看成绩并导出 Excel

三项任务同一时间只能运行一项。

### 账号管理

手动添加：填写账号、密码、备注（可选），点「添加」。

表格导入：点击或拖拽上传表格，支持 `.csv`、`.txt`、`.xlsx`、`.xlsm`。

表格示例（号码仅为脱敏示例，请填写真实账号）：

| 账号 | 密码 | 备注 |
| --- | --- | --- |
| 138****0000 | 你的密码 | 张三 |
| 139****0001 | 另一个密码 | 李四 |

- 首行表头会自动识别（账号 / 用户名 / 手机号、密码、备注 / 姓名）
- 没有表头时，默认第 1 列为账号、第 2 列为密码、第 3 列为备注
- 表格可用 UTF-8 或 GBK 编码；旧版 `.xls` 请先另存为 `.xlsx`
- 重复账号会自动跳过，并在上传区域下方提示原因
- 可点击「下载模板」获取带说明的 CSV 模板（以 `#` 开头的行会被忽略）
- 账号列表中的手机号以脱敏形式显示

### 通用设置

| 设置 | 适用功能 | 说明 |
| --- | --- | --- |
| 站点地址 | 全部 | 测试站 `https://cspsjtest.noi.cn`，正式站 `https://cspsj.noi.cn` |
| 下载目录 | 准考证、证书 | 可手动输入，或点「浏览…」选择；点「打开」查看 |
| 目录结构 | 准考证、证书 | 按活动区分（默认）/ 按用户区分 / 不区分 |
| 文件名格式 | 准考证 | 默认 `{original}`，保持服务端原始文件名；证书使用固定命名 |
| 登录等待 | 全部 | 单个账号等待登录完成的最长时间，默认 60 秒 |
| 账号间隔 | 全部 | 相邻账号之间的等待，默认 1 秒，降低风控概率 |
| 显示浏览器窗口 | 全部 | 遇到图形 / 滑块验证码时勾选，可手动完成验证码 |
| 包含历史活动 | 准考证 | 证书始终查询当前与历史活动；成绩查询始终只查历史活动 |

### 下载目录与命名

目录结构对**准考证**和**证书**同时生效，默认按活动区分。

**准考证（按活动区分）**

```
<下载目录>/
├── NOIP 2026/
│   └── LN-0000张三.pdf
└── CSP-S 2026 第一轮认证/
    └── LN-0001李四.pdf
```

**证书（按活动区分）**

```
<下载目录>/证书/
├── NOIP 2026/
│   └── NOIP 2026_获奖证书_LN-0000张三.pdf
└── CSP-S 2026 第一轮认证/
    └── CSP-S 2026 第一轮认证_等级证书_证书.pdf
```

选择「按用户区分」时，准考证使用 `<下载目录>/用户/`，证书使用 `<下载目录>/证书/用户/`；选择「不区分」时，准考证直接放在 `<下载目录>/`，证书直接放在 `<下载目录>/证书/`。用户目录名使用备注 + 脱敏账号，不会包含完整手机号。

**准考证文件名模板**（默认 `{original}`）：

| 占位符 | 含义 |
| --- | --- |
| `{original}` | 服务端原始文件名（不含 `.pdf`） |
| `{activity}` | 活动名称 |
| `{user}` | 备注 + 脱敏账号（与用户目录名一致） |
| `{account}` | 脱敏账号 |
| `{note}` | 备注 |
| `{id}` | 活动 ID |
| `{date}` | 下载日期（YYYYMMDD） |

扩展名 `.pdf` 会自动补全。例如：按用户区分 + `{activity}_{original}` → `张三_138xxxx0000/NOIP 2026_LN-0000张三.pdf`。

**证书文件名固定为**：`活动名称_证书类型_服务端原始文件名.pdf`，不跟随准考证模板。

文件重名时会自动追加 `(2)`、`(3)`。

### 功能一：准考证下载

1. 点击「开始下载（N 个账号）」。
2. 页面实时显示进度、当前账号与运行日志。
3. 任务结束后显示完成情况：账号总数、成功 / 失败统计、下载份数、未下载活动数与用时。
4. 每个账号的结果包含已下载文件与跳过原因；点击「打开下载目录」查看文件。

默认只处理当前活动；勾选「包含历史活动」后会同时遍历历史活动。未开放准考证的活动会自动跳过。

### 功能二：证书下载

1. 在「证书下载」卡片中勾选类型：
   - **获奖证书**（默认勾选）
   - **等级证书**（可选）
2. 点击「下载证书」。
3. 工具依次登录账号，遍历当前与历史活动，尝试下载对应证书。

- 保存位置：`<下载目录>/证书/`，沿用目录结构设置
- 文件名：`活动名称_证书类型_服务端原始文件名.pdf`
- 未开放、无证书、非 PDF 响应等情况会跳过，并列出原因
- 结果区显示下载份数、成功 / 部分成功 / 失败账号数；「打开证书目录」可直接查看

### 功能三：历史成绩查询

1. 点击「查询历史成绩」。
2. 工具依次登录账号，读取「历史活动」并查询每个活动的成绩。

显示内容：

- 按活动分组，每个账号一行：账号（脱敏）、备注、姓名、准考证号、各题得分、总成绩、成绩备注
- 各题得分既按题目名分列展示，也有「各题得分」列逐题列出题目名与分数（如 `crystal 25；subway 0`）
- 不同活动的题目列会自动对齐；某账号缺少某题时显示 `—`
- 缺考、暂无成绩信息、查询失败的账号会明确标注

点击「导出表格」生成 Excel：

- **成绩汇总**：所有账号与活动的总表
- **题目得分明细**：一行一题，包含账号、活动、姓名、准考证号、题目名称、得分
- **每个活动一个工作表**：账号、备注、姓名、准考证号、各题得分、总成绩、成绩备注
- 文件名形如 `历史成绩_20261125_1530.xlsx`

> 成绩数据包含姓名与准考证号等个人信息，导出的表格请妥善保管。

## 命令行版（仅准考证下载）

命令行版适合单账号或脚本调用，**仅支持准考证下载**；证书下载与成绩查询请使用网页版。

```bash
# 交互式输入账号密码（密码不回显）
python download_tickets.py

# 直接传参
python download_tickets.py -u 你的账号 -p "你的密码"

# 同时遍历历史活动，并指定目录
python download_tickets.py -u 账号 -p 密码 --history -o "D:\准考证"

# 显示浏览器窗口（处理验证码）
python download_tickets.py -u 账号 -p 密码 --headed
```

参数说明：

| 参数 | 说明 |
| --- | --- |
| `-u, --user` | 用户名 / 手机号 / 邮箱 |
| `-p, --password` | 密码（不填则交互式输入） |
| `--base-url` | 站点地址，默认 `https://cspsjtest.noi.cn` |
| `-o, --out` | 保存目录，默认 `./tickets` |
| `--history` | 同时遍历「历史活动」 |
| `--only-enrolled` | 仅处理已报名的活动 |
| `--page-size` | 每页活动数，默认 50 |
| `--headed` | 显示浏览器窗口 |
| `--login-timeout` | 登录等待秒数，默认 60 |

命令行版的文件名固定为「活动名_原始文件名.pdf」，不使用网页版的目录结构与文件名模板设置。

退出码：`0` 正常；`1` 执行异常；`2` 登录失败；`3` 接口解析失败。

## 工作原理

所有功能共用同一条登录流程：使用 Playwright 打开登录页，填写账号密码，获取会话 Cookie。随后通过活动列表接口 `/api/contestant/activity/list` 获取活动与活动 ID（该接口使用自定义二进制协议，程序已内置编解码）。

| 功能 | 请求接口 |
| --- | --- |
| 准考证下载 | `/api/contestant/activity/download_ticket?id=<活动ID>` |
| 获奖证书 | `/api/contestant/activity/download_prize_certificate?id=<活动ID>` |
| 等级证书 | `/api/contestant/activity/download_grade_certificate?id=<活动ID>` |
| 成绩查询 | `/api/contestant/activity/get_score_info?id=<活动ID>` |

成绩数据以 100 为系数存储，展示时换算为实际分数。接口返回的错误消息（如「未开放下载准考证」「暂无成绩信息」「会话已过期」）会被解析并展示为跳过或失败原因。

## 安全与隐私

- 网页服务默认只监听 `127.0.0.1`，仅本机可访问；
- 账号密码只保存在运行中进程的内存里，网页不回显密码，关闭服务即清除；
- 手机号在界面、接口返回、运行日志和下载目录名中均脱敏（如 `138****0000`），不会出现完整号码；
- 浏览器本地存储（localStorage）只保存站点地址、下载目录等设置，不保存密码；
- 下载的准考证、证书和导出的成绩表格包含姓名、准考证号等个人信息，请妥善保管，不要随意分享；
- 请只操作本人账号或已获得授权的账号，并遵守网站使用条款。

## 常见问题

**1. 登录失败，或报 `net::ERR_CONNECTION_CLOSED`**

连续大量登录可能触发站点风控。处理方式：

- 等待几分钟后重试；
- 增大「账号间隔」；
- 勾选「显示浏览器窗口」，在登录等待时间内手动完成验证码；
- 先用普通浏览器确认账号能正常登录、密码未过期。

**2. 提示「未开放下载准考证」**

活动尚未开放准考证下载，或下载通道已关闭，与程序无关。可在活动详情页查看准考证开放时间。

**3. 证书下载全部跳过**

可能原因：

- 活动尚未开放证书下载或该活动不提供证书；
- 该账号没有对应类型的证书（获奖证书与等级证书是不同的）；
- 服务端返回的不是 PDF。

可分别尝试勾选「获奖证书」「等级证书」，或在网站活动详情页确认证书状态。

**4. 成绩查询没有结果**

成绩查询只遍历「历史活动」。如果活动尚未公布成绩、账号未参加或缺考，会显示「暂无成绩信息」或「缺考」。可先在网站确认成绩是否已发布。

**5. 表格导入失败**

- 确认扩展名为 `.csv` / `.xlsx`；
- 首行建议使用表头：`账号,密码,备注`；
- 旧版 `.xls` 请另存为 `.xlsx`；
- 检查是否有空账号、空密码行（会提示具体行号）。

**6. 端口被占用**

默认使用 8765，被占用时会自动顺延。以控制台打印的地址为准，或使用 `--port` 指定其他端口。

**7. 下载目录无法写入或打开**

确认路径存在且有写权限；网页端可用「浏览…」重新选择。路径支持相对路径（相对于项目目录）和绝对路径。

**8. 网页打不开**

确认启动窗口未被关闭，且安全软件没有拦截本地端口；访问控制台打印的地址。

**9. 切换到正式站**

在网页「站点地址」中改为 `https://cspsj.noi.cn`，或命令行使用 `--base-url https://cspsj.noi.cn`。建议先用测试账号验证。

**10. 为什么多账号是串行执行？三项任务不能同时运行？**

串行登录更稳定，也能降低触发风控的概率。准考证下载、证书下载、成绩查询共用登录流程，同时运行会加剧风控风险，因此程序中互斥执行。大规模使用时建议适当增大账号间隔，分批执行。
